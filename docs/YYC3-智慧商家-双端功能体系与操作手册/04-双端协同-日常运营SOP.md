# 双端协同 · 日常运营 SOP

> 版本:v1.0(2026-11-01)
> 原则:**PC 管规则与数据,App 管现场与交易;每个动作都有报表归宿。**

---

## 一、角色 × 端 × 职责矩阵(RACI 简版)

| 角色 | PC 后台 | App | 责任边界 |
| --- | --- | --- | --- |
| 主账号 | 全模块 + 高危操作批准 | 巡查 + 复核 | 唯一可批「清空数据/改账单/关密码防线」 |
| 系统管理 | 员工、设置、打印机、VOD | 设备绑定 | 只改配置不做交易;改动留《设置变更登记表》 |
| 运营管理 | 商品、套餐、价格、广告位 | 现场督导 | 价格与套餐唯一维护人 |
| 营销总监 | 会员规则、券、报表看板 | 会员/营销/订台 | 会员资产与营销业绩 |
| 收银 | 支付流水/交接报表(查) | 开房、点单、结账、交接班 | 当班现金流第一责任人 |
| 仓管 | 仓库全模块 | 出入库任务、盘点 | 库存准确率 |
| 营销员/服务员 | — | 绑客、订台、送花 | 业绩归属 |
| 艺人主管 | 艺人列表、艺人设置(查) | 报备、签到、上下钟 | 艺人台费准确 |

## 二、日节奏(营业日 08:00 为报表日切点)

### 开店前(PC + App,15 分钟)

1. PC 登录 → 看「营业收入日报表」昨日数 + 异常(退款/挂账/免单)。
2. App 消息中心清零:过夜预警(麦克风低电量/寄存到期/库存不足)逐条处理。
3. 状态图巡检:清洁完成、待清洁包厢清空;设备自检(门锁/触摸屏/打印机测试单)。
4. 促销核对:今日套餐/价格策略/走马灯/欢迎词与运营方案一致(节假日套餐「适用日期」是否覆盖今日)。

### 营业中

- **每 2 小时**:状态图全巡——到时包厢及时续时/关房;营业额预警包厢重点跟进。
- **实时**:消息驱动——呼叫服务、配送、自助存酒、扫码点单出品;先消息后动作,完成即消。
- **大额/敏感**:经理打折、赠送、挂账、免单 → 当班二次确认(密码+备注),当晚录入《特殊账单台账》。
- **艺人线**:报备→签到→上钟→下钟全在 App;台票/台费异常当班结清。

### 打烊(收市后)

1. App 收银交接:生成交接单 → 打印 → 现金/刷卡/线上分渠道清点核对。
2. PC「收银交接汇总报表」与 App 交接单双向核对;差异当场查「支付流水」。
3. 挂账/欠款登记,担保人签字(电子留痕)。
4. 清洁任务派发完成;客遗登记入库。
5. PC 导出当日:营业收入日报、账单汇总、商品销售汇总、会员日报(归档到门店云盘/文件夹 `yyyy-mm-dd/`)。

## 三、周节奏

| 日 | 动作 | 端 |
| --- | --- | --- |
| 周一 | 周经营复盘会:营业平衡表 + 商品盈利汇总 + 订台业绩汇总;定本周促销 | PC |
| 周二 | 会员运营:生日报表拉名单 → 群发/礼包;沉睡会员(消费明细筛 30 天未到店) | PC+App |
| 周三 | 库存周盘:实时库存 + 缺货清单 → 采购进货单;售货柜补货 | PC+App |
| 周四 | 价格与套餐检视(竞对/毛利:商品盈利明细);调价走变更登记 | PC |
| 周五 | 周末备战:套餐上架/推举、广告位与走马灯换新、排队叫号语音、备用零钱 | 双端 |
| 周日 | 艺人周结:上下钟汇总 + 台费流水 → 结算表 | PC |

## 四、月节奏

1. **月结**:营业平衡表(商务版)+ 进销存 + 盘点盈亏 → 成本毛利表;会员充值/消费/积分三大报表 → 会员资产负债表。
2. **账号审计**:员工列表过一遍(离职即禁用);操作日志抽查敏感动作(打折/赠送/改账单/清数据)。
3. **设置巡检**:密码验证族全开确认;审批开关状态确认;打印模板与账单显隐符合财务要求。
4. **备份**:导出会员资料报表 + 寄存汇总 + 全月账单明细,异地存一份(注意:清空数据不清会员与寄存,但备份是最后防线)。
5. **变更窗口**:套餐/计费/设置类调整统一在**每月 1 号非营业时段**实施(避开营业中口径突变)。

## 五、十大高频场景 SOP(双端联动)

1. **新商品上市**:PC 建类型(如无)→ 录商品(属性/价格/订台业绩)→ 上架销售=是、消费者端显示=是 → App 点单验证 → 微信端可见性验证。
2. **节假日套餐**:开房套餐名称建团购/酒水套餐 → 价格页设适用日期+跨时段 → 推举上架 → 节后下架。
3. **包厢调价**:计时开房列表改档(或包段价格管理,注意**整房型切换**效应)→ 当晚开房验证 → 次日报表核对。
4. **会员活动**:PC 定充赠/限时会员 → App 办卡充值验证到账 → 会员消费明细核对赠送账户。
5. **存酒到期**:App 消息/PC 寄存管理拉到期清单 → 通知取酒 → 未取自动充公(PC 天数)→ 充公汇总报表留痕。
6. **售货柜缺货**:App 缺货预警 → 补货(仓→柜)→ PC 进销存自动核减。
7. **顾客投诉账单**:App 查账单 → PC 账单查看核对 → 需改走「账单制作」双人复核 → 退款走审批流。
8. **设备故障**:App 远程重启(音量/云音乐/门锁)→ 无效则查 PC VOD room 参数 → 报修单(App 提交,PC 审批)。
9. **员工入离职**:PC 员工列表新增/禁用 → 新人 App 首登改密 → 离职当日禁用并交接(交接单+钱包码失效确认)。
10. **换班收银**:App 结清在途单 → 交接单打印签字 → 新班登录(刷卡业务账号密码验证开)→ PC 交接汇总核对。

## 六、异常处置速查

| 症状 | 先查 | 再查 |
| --- | --- | --- |
| App 连不上 | 网络 → `ktv-app.ucmbar.com` 连通性 | 账号是否被禁用 |
| PC 登录异常 | 浏览器(换 Chrome) | 密码（从本地密钥库取，勿写入文档） |
| 打印不出单 | App 收银机绑定 | PC 打印机规则与勾选单据 |
| 触摸屏不显示商品 | 商品「消费者端显示」 | 价格策略是否排除该包厢 |
| 计费口径不对 | 包段价格管理是否覆盖该房型 | 套餐跨时段/不满一小时开关 |
| 会员价未生效 | 会员价是否 0(=优惠价) | 「折扣仅会员支付生效」开关 |
| 存取酒异常 | 存取酒仓库设置 | 出货仓规则 |
| 报表对不上 | 是否跨营业日/含退款退货 | 报表默认检索时间设置 |
