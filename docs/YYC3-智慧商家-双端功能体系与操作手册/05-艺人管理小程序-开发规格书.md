# 艺人管理小程序 · 开发规格书

> 版本:v1.0(2026-11-01)|依据:智慧商家 App「艺人管理」模块 **25 子模块全量实抓** + PC 端配置/报表清单

## 四、核心业务流

### 4.1 艺人入驻流(自助)

```
门店出示「艺人注册二维码」或「资料自助绑定码」
→ 艺人微信扫码 → 填资料(必填项受 PC 配置) → 绑定微信
⚠️ 规则〔实测红字〕:若微信已绑定其他门店,本次绑定后系统自动删除原门店资料(微信身份全局唯一)
```

### 4.2 每日考勤流

```
艺人到店 → 微信扫门店「报备码」签到(报备类型自选:签到/陪宴/私事/早退/迟到/例假/其他)
→ 状态进入实时看板 → 主管可视(报备明细/汇总按组×主管)
→ 漏打/错打 → 管理端「补打卡」(带类型与原因)
→ 离店 → 扫码签退(签退时间+地理位置留痕)
约束〔PC 艺人设置〕:签到后满 N 分钟方可签退;未签到是否允许上钟打卡可配
```

### 4.3 上钟计费流

```
包厢开房 → 选艺人上钟(上下钟) → 计时中(实时状态=上钟紫点)
→ 下钟(PC 可配手动扫码下钟) → 按台费规则(等级×房型)计费
→ 台费计入包厢账单/艺人台费流水(扣费) → 结算
约束:总上台次数上限/允许串台数/首台最低时长/同包厢最低时长(档案级限制)
```

### 4.4 台费资金流

```
充值: 现金 / 抖音 → 台费余额+
扣费: 上钟自动 / 管理员手动扣费(金额+确认) → 台费余额−
全程流水: 充值记录/扣费记录/手动扣费,均可按营业日+腰牌号检索,总金额汇总
```

### 4.5 台票流

```
PC/小程序配置台票规则 → 艺人购买(现金/抖音) → 上钟核销使用
→ 购买/使用双流水+汇总
```

### 4.6 展示与评价流

```
艺人微信扫码登录「艺人展示」个人主页(照片/等级/标签对外展示)
管理端「展示控制台」:选择当前包厢/当前组别投放展示(可更换)
顾客消费后评价 → 艺人服务评价列表(PC 报表同步)
```

## 八、红线与合规建议

1. 台费=艺人薪酬资金流:**充值/扣费双流水不可逆**,手动扣费建议加审批+备注必填
2. 身份证/照片为敏感个人信息:加密存储,展示端脱敏
3. 微信绑定唯一性:跨店转移必须二次确认并留原店资料删除日志〔实测为自动删除,建议小程序改为可配置〕
4. 上下钟计费口径变更需审计留痕(对齐主系统《设置变更登记》惯例)
5. 营业日口径(08:00 日切)全模块统一

## 九、开发优先级建议(MVP → 完整)

- **MVP(第 1 期)**:档案+等级/组别+台费规则+上下钟+报备(签到签退)+台费流水 —— 跑通"人/考勤/钱"三主线
- **第 2 期**:台票全套+订单+评价+实时状态看板
- **第 3 期**:展示控制台/个人主页+预约管理+PC 报表对齐+审批中心接入
