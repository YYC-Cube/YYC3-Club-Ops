## 1. 销售

### 1.1 订单列表

- **用途**:查询门店每一笔销售单据。
- **筛选**:时间段(默认当日 08:00 起)、消费门店、包厢号、区域、订单类型、支付状态、支付类型、订单来源、订单编号、导购员工、操作人。
- **汇总条**:消费金额 / 实收金额 / 退款总额(随筛选实时小计)。
- **操作**:查询 → 导出(Excel)。
- **建议**:日结对账以「支付状态 + 当日班次」过滤后与 App 交接单核对。

### 1.2 账单列表

- 查询/查看每个账单(包厢维度、含开房套餐与商品合并账单)。用于客诉追溯、退款定位。

### 1.3 在线预订 / 预订列表

- 查看微信端顾客自助提交的预订(预订类型受「微信在线预订类型」设置控制),跟进转化。

### 1.4 支付流水

- 逐笔支付/退款流水(微信、支付宝、现金、刷卡、团购、会员账户等),对账 disputes 时以本页 + 订单列表交叉。

## 2. 商品(14 个子模块)

### 2.1 商品管理(商品列表 / 商品类型 / 商品口味)

**先建类型与口味,再录商品。**

- **商品类型**:新增 → 名称 + 显示顺序(大者靠前)→ 保存。「消费者端显示=是」则在触摸屏/微信/支付宝/App 全端显示,=否 仅 App 可见。
- **商品口味**:按需添加,供商品勾选。
- **商品列表新增**(支持模板批量导入:下载模板 → 按格式整理 → 导入;**导入前必须先建好商品类型**):
  - **条码**:扫码枪读入;「+」可加多码;支持一物多码、一码多物。
  - **名称/别名**:名称=跨门店调拨显示名;别名=门店销售显示名(不填默认同名称)。
  - **单位**:下拉选或「+」新增。
  - **价格**:原价(仅展示)/ 优惠价(非会员价)/ 会员价(0=同优惠价;可与会员折扣叠加);支持**分等级会员价**。
  - **属性开关**:赠送商品 / 允许打折 / 销售商品(否=各售卖入口隐藏,仍可做套餐/配送/赠送)/ 推荐商品 / 属低消 / 消费者端显示 / 算订台业绩(可设提成金额或百分比,二选一)。
  - **图片**:本地上传;**资料同步**:连锁门店勾选同步。
  - **口味**:勾选已建口味。

### 2.2 商品套餐列表

新增套餐(资料同商品)→ 添加套餐商品(搜索 → 勾选 → 设数量)→ 提交。用于多商品打包销售。

### 2.3 开房套餐名称 / 开房套餐价格

**名称页定类型,价格页定档位。** 四类套餐:

| 类型 | 构成 | 说明 |
| --- | --- | --- |
| 时间套餐 | 仅时间费 | 只收时长 |
| 酒水套餐 | 时间 + 商品(商品必选) | 最常用 |
| 最低消费套餐 | 包厢低消 | 低消余额可购房费与商品 |
| 团购套餐 | 时间 + 商品(可选) | 与团购平台一致;本地开房输团购券号,可用于微信预订 |

价格页关键字段:时长原价(必填,展示用)、团购结算价(核算用)、适用包厢(多选,每类型生成一条)、使用时间/有效星期/不可用日期(剔节假日)/适用日期(节假日套餐)、**跨时段是否可用**(是=可超时唱完,否=到点停)。
操作:保存后可推举(微信/支付宝首页推荐)、修改、禁用、删除、复制新增;团购套餐可预定上/下架。删除套餐名称会连带删除其价格。

### 2.4 计时开房列表(计时/包断/低消)

按「时段 × 包厢类型」设档:

- **计时单价 / 会员计时单价**:按小时收;
- **低消金额 / 会员低消**:按低消收;
- **酒水不满低消设置**:收至低消金额(酒水+时间费补齐低消)或收实际时间费;
  例:计时 200/h、低消 800,消费 3h 酒水 500 → 收至低消=800;收实际时间费=500+600=1100。
- **包段金额 / 会员包段**:整段一口价。
- **优先级**:「包段价格管理」>「计时开房设置」,按包厢类型整组生效——一旦某房型在包段价格管理里有任一规则,该房型的计时设置全部失效,以包段页为准(未覆盖房型仍走计时页)。
- **不满一小时按小时算**(2.5):开关,控制计时进位。

### 2.6 商品配送

- **固定配送**(买 X 送 Y):购满起购数自动配送;**手工配送**:购满后可选指定物品(可限数量),出品时在支付页改配送内容。

### 2.7 开房小吃

开房时自动销售/赠送的商品(收费小吃 & 免费小吃)。例:12–18 点小包开房自动赠小果盘。

### 2.8 价格策略

同商品在不同包厢/区域不同价。例:会所区价 > 自助区价。也可控制包厢只显示策略内商品。

### 2.9 积分兑换

设商品兑换积分;会员在微信端用积分兑换。

### 2.10–2.14 其余子模块

自助大厅商品推荐类型设置 / 商品免单规则设置 / 花管理(花单商品与价位)/ 首次下单必点商品设置。

## 3. 仓库(12 个子模块)

| 子模块 | 操作路径 | 要点 |
| --- | --- | --- |
| 仓库管理 | 仓库→仓库管理→新增仓库 | 一店可多仓;**存取酒仓库每店至多一个**(设了它,存取酒出入库都走它;不设则按出货仓规则)。本店现设:总仓、存/取/回收仓 |
| 出货仓管理 | 仓库管理→新增出货仓 | 定义"某区域销售从哪个仓出货、扣哪个仓库存" |
| 供应商管理 | 添加供应商→名称/联系人/电话 | 采购前提 |
| 采购进货 | 新增进货单→数量→保存 | 入库到指定仓 |
| 采购退货 | 新增退货单→数量→保存 | 退供应商 |
| 库存调拨 | 新增调拨单 | 同店跨仓 & 跨门店(商品"名称"字段用于跨店显示) |
| 报损单 | 新增→数量→保存 | 损耗留痕 |
| 领用单 | 新增→数量→保存 | 员工内部领用 |
| 库存盘点 | 新增盘点单→获取系统实时库存→录实际库存→保存 | **开始时间固定为上次盘点结束**;结束时间不填=取当下库存,回填历史需选对应日 08:00 |
| 实时库存 | 查询 | 可按类型/库存排序,设最小库存预警、查缺货 |
| 寄存管理 | 查询 | 客户存酒信息总览 |
| 库存不足是否出货 | 新增设置 | **优先级大于门店设置的同名开关**;典型用法:厨房物品可出货、零售不可出货 |

**盘点时点规则**(营业 13:00–02:00 为例):午夜收市后在次日 13:00 前盘完 → 结束时间可不填;13:00 后录入 → 结束时间选当日 08:00。

## 5. 员工

### 5.1 员工列表

- 筛选:服务门店 / 职位 / 姓名 / 状态 / 组别。
- **新增**:录入组别、姓名、工号、手机号、职位、状态(启用/禁用)。手机号即 App 登录号。
- **批量**:下载《员工资料模板》(OSS)→ 按格式填写 → 导入。
- 操作:禁用 / 删除。**禁用即冻结 App 登录,优先用禁用而非删除**(保留历史归属)。

## 6. 设置(26 个子菜单 + 门店设置中枢)

### 6.1 门店设置(8 大类 100+ 开关)——改动即生效于全端

**营业设置(62 项)按族归类速查:**

| 族 | 关键开关 | 默认建议 |
| --- | --- | --- |
| 支付族 | 微信/支付宝端支付方式、app 支付方式(4 种自定义)、自助大厅支付形式、账单自助付款 | 按门店收款渠道开 |
| 密码验证族 | 会员支付密码、经理实收密码、经理打折密码、商品赠送密码、挂账/担保人密码、刷卡业务登录密码、结账员工验证 | **全部开启** |
| 预警族 | 包厢营业额预警、开房剩余时长预警、会员到店预警、麦克风低电量提醒 | 按管理密度开 |
| 开房规则族 | 计时跨时段、取消开房时限、每次开房券总量、券是否打折、不满低消服务费口径 | 逐条过一遍并书面化 |
| 花单族 | 花单与账单合并支付、状态图是否含花单、收银交接是否含花单 | 与财务口径一致 |
| 会员族 | 刷卡手动输卡号、折扣仅会员支付生效、积分连锁通用、扫码默认办卡、资料必填项、条码显示、自助注册协议 | 按营销策略 |
| 其它 | 班次、报表默认检索时间、团购平台类型、排队叫号语音/独立排号、服务评价、暂停营业时间、全场霸屏、到店指引、智慧超市、短信模板、app 任务自动接收、历史任务细分到账号、下单默认导购员、订台业绩含未收款、划线价显示 | 按需 |

**其余 7 类**:单据设置(5)、寄存设置(8)、点歌系统设置(11)、仓库设置(2)、打印单据设置(16)、艺人设置(7)、系统设置(3,含清空数据高危项)。全量清单见《01-总览》第三节。

### 6.2 门店列表

商家账号下全部门店资料(连锁场景的新店入口)。

### 6.3 收银机设置 & 打印机设置(联动 App)

**标准链路**:PC 设收银机名称 → PC 添加打印机并选收银机 → 配打印规则 → 勾选要打的单据 → **App 个人中心绑定同一收银机** → 完成。
不打印某类总单:商品总单打印设置 → 打印总单设置 → 取消勾选。

### 6.4 VOD 在线设置(点播/灯光/播放)

- **大厅公视**:外接大厅转播盒转播球赛/表演到包厢(出厂已配)。
- **智能灯光**:中控走机顶盒 COM2(默认 `compac=/dev/ttyS2,6`);改 COM1 用 room 参数 `compac=/dev/ttyS1,6`;触摸屏与中控串口**不能同口**;组合码 48=组合关、49=组合开,paclist1–4 对应柔和/明亮/动感/抒情(按灯控数码管实测验码);自动灯光需 room 参数 `灯光自动控制=0`。
- **开房播放/开机播放**:上传 mkv/mp4/avi,≤1080p,单文件 ≤200M。
- **包厢配置(room)**:按包厢或全局个性参数(含电影模块开关)。

### 6.5 寄存设置

按商品类型设到期期限(如啤酒 30 天、红酒 60 天)。

### 6.6 抹零设置 / 抹零设置2

前者定全局规则(进位或四舍五入);后者按区域/订单/账单差异化抹零。

### 6.7 走马灯设置

包厢电视屏滚动字幕(欢迎语/促销)。

### 6.8 轮播歌曲设置 / 主题菜单歌曲设置 / 自定义曲库管理 / 缺歌反馈 / 影片管理

- 轮播歌:门店空闲时轮播(高清/排行/自定义)。
- 影片管理:触摸屏电影模块;需最新无狗点播包 + 服务器建目录 `vod/电影/××/××/××/影片`(层级必须) + 单片 ≤4G + room 参数开电影模块 + 重启机顶盒;支持批量导入。

### 6.9 审批与比例类

退款退货审批、商品赠送审批、报修审批、客遗回收入库审批(默认值在门店设置)、包厢赠送比例、业绩系数、包厢类型设置(房型与低消基座)、欢迎词、门牌机自定义、电视屏/点歌屏广告位、平板点歌 app 设置。

| 操作 | 风险 | 要求 |
