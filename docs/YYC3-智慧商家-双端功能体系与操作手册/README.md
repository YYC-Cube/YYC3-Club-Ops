## 快速上手(三分钟)

1. **认识体系**:打开 HTML 架构图「〇 体系总览」。
2. **能登录**:PC 后台 + App 地址见《01》环境信息卡;
3. **会巡场**:App 状态图 + 消息中心(《03》第 0–1 节)。
4. **守红线**:《04》第七节六条,贴墙。
